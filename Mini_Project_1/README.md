# 📱 Mini Project 1: Used Phones Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of a used smartphone dataset. The goal was to clean the raw data, analyze important features, and extract meaningful insights using Python data analysis and visualization libraries.

This project was completed as part of my **Artificial Intelligence Internship at Unlox Academy**.

---

## 🎯 Objectives

* Understand the structure of the dataset.
* Identify and handle missing values and duplicate records.
* Perform data cleaning and preprocessing.
* Analyze numerical and categorical features.
* Discover relationships between variables.
* Generate meaningful visualizations and insights.

---

## 📂 Dataset Information

The dataset contains information about used smartphones, including:

* Brand
* Model
* Release Year
* Usage Hours
* Battery Health
* Charger Included
* RAM
* Battery Backup
* Price
* City

### Dataset Files

* `used_phones_uncleaned_dataset.csv` → Original dataset
* `cleaned_used_phones.csv` → Cleaned dataset after preprocessing

## 🔍 Project Workflow

### 1. Data Exploration

* Dataset overview
* Shape and structure analysis
* Statistical summary

### 2. Data Cleaning

* Missing value checking
* Duplicate removal
* Data formatting
* Standardization of categorical values

### 3. Univariate Analysis

* Distribution of numerical features
* Analysis of categorical variables

### 4. Bivariate Analysis

* Price vs Battery Backup
* Brand vs Price
* Other feature relationships

### 5. Multivariate Analysis

* Correlation Heatmap
* Pairplot visualization

---

## 📊 Key Insights

* Smartphone price is influenced by multiple factors such as battery health, RAM, and battery backup.
* Data cleaning improves analysis accuracy.
* Visualizations help identify trends and patterns in the used phone market.
